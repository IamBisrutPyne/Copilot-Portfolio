# Copilot-Portfolio

A responsive portfolio website template created with GitHub Copilot using:

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Run locally

Open `/home/runner/work/Copilot-Portfolio/Copilot-Portfolio/index.html` in a browser, or serve the folder with a local static server.

## Customize

Update the content in `index.html` and adjust styles in `styles.css` to match your personal brand and projects.
